DETECTION RULE

A held-high signal counts once. Rearm at 70% of the threshold. Detection or gesture timing changes put the lamp to sleep.

03 Lamp behavior

Default rhythm: about 0.3–0.6 seconds between claps. A 0.7-second pause ends the sequence; the next clap starts a fresh command.

Brightness mode · no colors1 clap: wake → low → medium → high → off3 claps while awake: start colors
Color mode · lights already onRed → green → blue · smooth 5 s transitions1 clap: freeze color · 2 claps: turn off

The modes are separate: single claps change brightness only without colors. In colors, a single clap freezes the color and never changes brightness. Sleep only responds to one clap to wake.

Brightness stepBrightness · 0–255Cycle stop · 5 s each

Brightness steps use warm white. The three color swatches independently set the cycle palette.
